# Ansible – Trainingsmaterialien

Dieser Branch enthält die Materialien zur Durchführung des Ansible-Trainings. Hier finden sich **Beispiele**, **praktische Übungen** und **Hinweise für Trainerinnen und Trainer**.

- `resources/`: Beispiele und Übungen für die Teilnehmenden.
- `instructor/`: Trainerhinweise und Musterlösungen zu den Übungen.
- `training-environment/`: Dateien zur Vorbereitung und Nutzung der Trainingsumgebung.

Die allgemeine Seminarbeschreibung befindet sich im Branch `main`.

# Ansible – Training Materials

This branch contains the materials for delivering the Ansible training course. It provides **examples**, **hands-on exercises**, and **guidance for instructors**.

- `resources/`: Examples and exercises for participants.
- `instructor/`: Instructor guidance and model solutions for the exercises.
- `training-environment/`: Files for setting up and using the training environment.

The general course description is available on the `main` branch.
